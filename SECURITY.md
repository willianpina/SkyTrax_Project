# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | Yes                |
| < 1.0   | No                 |

Only the latest release on the `main` branch receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly. **Do not open a public issue.**

1. Send an email to **willianpina@protonmail.com** with:
   - A description of the vulnerability.
   - Steps to reproduce the issue.
   - The potential impact.
   - Any suggested fix, if applicable.

2. You will receive an acknowledgment within **48 hours**.

3. The maintainer will work with you to understand and validate the report, and will aim to release a fix within **7 days** for critical issues.

## Disclosure Policy

- Vulnerabilities will be disclosed publicly only after a fix has been released.
- Credit will be given to the reporter unless they prefer to remain anonymous.
- If a fix cannot be provided in a reasonable timeframe, the vulnerability will be disclosed with mitigation guidance.

## Scope

This policy applies to all code in this repository, including but not limited to:

- FastAPI backend and API endpoints.
- Scrapy crawlers and data pipelines.
- Database schemas and migrations.
- Frontend application.
- Docker and infrastructure configuration.
