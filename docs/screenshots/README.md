# Screenshots

Adicione capturas de tela da plataforma nesta pasta antes da publicação no GitHub.

## Recomendações

- Resolução: 1920×1080 ou 1440×900
- Tema: capturar versões **dark** e **light** se possível
- Dados: usar ambiente com seed realista (sem PII)
- Formato: PNG ou WebP
