# Roadmap (legacy)

## Phase 1: Scrapy Foundation

- AirlineQuality/Skytrax spider with pagination and Playwright support.
- PostgreSQL persistence with fingerprint deduplication.
- FastAPI analytics endpoints and executive dashboard.

## Phase 2: NLP Intelligence

- Transformer sentiment model.
- BERTopic training over embeddings.
- Entity normalization for routes, aircraft and service attributes.
- Semantic review search using pgvector.

## Phase 3: Competitive Benchmarking

- Airline rankings by rating, recommendation and sentiment.
- Topic gap analysis across airlines.
- Reputation risk scoring.

## Phase 4: Distributed Scraping

- Redis-backed crawl scheduling.
- Multiple source adapters.
- Spider run monitoring and alerting.
- Proxy pool integration if source policies and compliance requirements allow it.

## Phase 5: Strategic Automation

- LLM-generated executive insights grounded in review evidence.
- Reputation alerts for negative topic spikes.
- Geographic route dashboards.
- BI and warehouse export.
